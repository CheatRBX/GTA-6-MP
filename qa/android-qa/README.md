# android-qa (из плагина claude-android-qa-plugin)

Скрипты плагина `android-emulator-qa` без изменений, лицензия Apache 2.0 (LICENSE).
Используются в `.github/workflows/qa.yml` для проверки приложений CoraxOS в эмуляторе:
дамп UI, поиск элемента по тексту, тап по координатам из дерева UI, скриншоты, logcat.
